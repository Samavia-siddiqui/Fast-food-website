# Fast Food Website

A modern, responsive fast-food restaurant website designed with a premium dark theme, animated UI, and a smooth single-page app experience. Built using React, TypeScript, Vite, and Tailwind CSS, the project includes a landing page, menu showcase, about section, and contact form.

## Overview

This project is a polished restaurant web experience for showcasing signature dishes, beverages, desserts, and contact details. It is designed to feel contemporary and engaging, with strong visual hierarchy, rich imagery, and elegant card-based layouts.

## Features

- Modern hero section with bold food marketing messaging
- Multi-page navigation using React Router
- Responsive menu gallery with category-based food cards
- Featured dishes and premium menu highlights
- About page with brand and dining experience information
- Contact section with inquiry form layout and business details
- Dark luxury theme enhanced with gradient accents and soft shadows
- Optimized for desktop and mobile viewing

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React
- PostCSS and Autoprefixer

## Getting Started

### Prerequisites

Make sure you have the following installed on your machine:

- Node.js (v18 or later recommended)
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Samavia-siddiqui/Fast-food-website.git
```

2. Navigate into the project directory:

```bash
cd Fast-food-website
```

3. Install dependencies:

```bash
npm install
```

### Run Locally

Start the Vite development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal, usually:

```bash
http://localhost:5173
```

## Available Scripts
